# 🌍 Global Wanted Database

## Описание
Система для агрегации данных о разыскиваемых лицах из открытых API правоохранительных органов со всего мира.

## Источники данных
- FBI Most Wanted (США)
- INTERPOL Red Notices (Международный)
- US Marshals 15 Most Wanted (США)
- EUROPOL Most Wanted (Европа)
- МВД РФ (Россия)

## Функционал
- ✅ Автоматический сбор данных каждые 5 минут
- ✅ AES-256 шифрование всей базы данных
- ✅ JWT-авторизация
- ✅ Фильтрация по имени, стране, возрасту, полу, статусу, источнику
- ✅ Экспорт данных
- ✅ Автоматическое резервное копирование
- ✅ Готов к деплою на Render.com

## Установка и запуск
1. Клонируйте репозиторий
2. Установите зависимости: `npm install`
3. Инициализируйте базу: `npm run init`
4. Запустите сервер: `npm start`

## Деплой на Render.com
- Используйте Dockerfile из папки `deploy/`
- Настройте переменные окружения

## Безопасность
- База данных шифруется AES-256
- Пароль хешируется с помощью bcrypt
- JWT токены истекают через 24 часа
- Все соединения через HTTPS

## Авторизация
- Логин: admin
- Пароль: устанавливается в .env

## Структура
- `/backend` - серверная часть
- `/frontend` - веб-интерфейс
- `/config` - настройки и ключи шифрования
- `/scripts` - утилиты (инициализация, бэкапы)
- `/deploy` - файлы для деплоя
